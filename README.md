# LPG Gas Management System

## Overview

The **LPG Gas Management System** is a full-stack web application developed to manage LPG cylinder distribution and customer records efficiently.
The system helps administrators track gas cylinder inventory, manage customers, and monitor daily transactions.

This project was built using **PHP, MySQL, HTML, CSS, and JavaScript**.

---

## Features

* User authentication (Login system)
* Customer management
* Gas cylinder tracking
* Daily checklist management
* Cash-in-hand tracking
* Asset management
* Simple and responsive user interface

## Installation Guide

1. Download or clone the repository

```
git clone https://github.com/your-username/LPG-Gas-Management-System.git
```

2. Import the database file into MySQL

```
database.sql
```

3. Update database connection in the PHP configuration file.

Example:

```php
$conn = mysqli_connect("localhost","your_db_user","your_password","your_database");
```

4. Run the project on a local server such as **XAMPP** or **WAMP**.
